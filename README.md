# Chief Roast Office

A small office for big claims. Bring one idea, get one blunt verdict and one useful fix, then return to the same case.

## Telegram private pilot

Open [@ChiefRoastOfficeBot](https://t.me/ChiefRoastOfficeBot) and send `/start`, then `/case your idea`.

- `/case text` opens your own case (up to 1,000 characters).
- `/status ACK` checks your receipt.
- `/return CRO-000001 7` records whole minutes spent on your correction in the same case.
- `/stop` closes your session and erases retained case content/results. Old receipts cannot retrieve stopped results.

The pilot uses a fixed set of Chief responses, chosen by theme, with a practical correction. It is entertainment and an invitation to improve an idea. Keep personal secrets and financial credentials out of your case.

The static reception, game and fictional gallery are being added here. GitHub Pages is not yet verified live. This public repository contains only public UI and fictional examples. The service backend and private credentials remain outside this repository.
